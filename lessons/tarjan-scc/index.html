第 1 课 · 动机与直觉 约 3 分钟

为什么有向图需要“强连通分量”与缩点？

无向图里“连通”很简单，顺着边能走到就行；但在单行道（有向图）里，你能去到对方，对方未必能回来——这就引出了强连通分量（SCC）。

1. 什么是强连通分量（SCC）？

在有向图中，如果一个点集内部任意两点 u 和 v 都能互相到达（u → ... → v 且 v → ... → u），并且再也加不进其他点了，这个极大的点集就叫一个强连通分量（Strongly Connected Component, SCC）。

  • 生活类比：城市里的单行道网络。同一个 SCC 里的路口“进了就能互相串门”；一旦开出这个 SCC 走到外面的单行道，就再也回不来了。
  • 孤立点也算：如果一个点没法在任何环里待着，它自己单独构成一个大小为 1 的 SCC。

2. 核心威力：缩点（Condensation）把“带环乱图”变成 DAG！

现实与竞赛中，很多图论算法（如拓扑排序、DAG 上动态规划）最怕遇到“环”——一旦有环，DP 状态就会无限循环转移。而如果把每个 SCC 缩成一个超级大点，原图就彻底消除了所有环，变成了一张干净的有向无环图（DAG）！

把每个强连通分量缩成一个超级点后，任意有向图都会变成可以拓扑排序和 DP 的 DAG

第 2 课 · DFS 森林与时间戳 约 3 分钟

时间戳 dfn 与有向图的四种边

Robert Tarjan 发现：只需要一次深度优先搜索（DFS），给每个点盖上“入场时间戳”，就能顺藤摸瓜把所有环揪出来。

1. 什么是 dfn[u] 和栈 stk？

  • dfn[u]（Discovery Time）：节点 u 第一次被 DFS 访问到时的时间戳（全局计数器 ++tim）。一旦赋值，永不改变。
  • 维护一个栈 stk 和标记 ins[u]：每次刚访问到 u 就把它压入栈中（ins[u] = true），代表“当前正在探索、还没确定归属的候选节点”。

2. DFS 视角下，有向边 u → v 只有三种实战情形

当我们在 tarjan(u) 里枚举出边 u → v 时，看 v 的状态只会出现以下情况：

边的类型判断条件含义与处理
树边（Tree）!dfn[v]v 还没访问过，递归 tarjan(v)；回溯时用 low[v] 更新 low[u]。
指向栈内（Back / 返祖）dfn[v] > 0 && ins[v]v 还在栈里！说明 v 是还没结束的祖先（或同支路点），构成环！用 dfn[v] 更新 low[u]。
指向栈外（Cross / 横叉）dfn[v] > 0 && !ins[v]v 早就弹栈归属了另一个已完成的 SCC，绝对不可能从 v 回到 u，直接忽略！
新手最容易问：为什么不能只写 else，一定要写 else if (ins[v])？
假设点 2 已经自己弹栈形成了 SCC 1 = {2}（此时 ins[2] = false），后来点 1 有一条单向边 1 → 2。虽然 dfn[2] < dfn[1]，但 2 根本回不到 1！如果不检查 ins[v]，1 就会误以为自己能通过 2 回到更早的时间戳，导致把本不该合并的点强行绑在一起。

第 3 课 · 算法灵魂 约 4 分钟

核心灵魂：low[u] 的传递与弹栈

如果说 dfn[u] 是出生证明，那么 low[u] 就是“我能靠着小弟和捷径，最多追溯到多早的祖先”。

1. low[u] 的精确定义

low[u] = u 及其子树节点，通过最多一条“指向栈内的边”，能追溯到的最小 dfn

在代码里只有两处会更新 low[u]：

  1. 树边回溯时：low[u] = min(low[u], low[v]) —— “我儿子 v 能回到那么早，那我也能顺着儿子回到那么早”。
  2. 撞见栈内节点时：low[u] = min(low[u], dfn[v]) —— “我自己直接抄近道连回了栈里的 v”。

2. 为什么 dfn[u] == low[u] 就刚好能弹出一整个 SCC？

当 tarjan(u) 跑完所有出边准备返回时，如果发现 dfn[u] == low[u]，意味着什么？

这意味着：u 和它子树里所有还没弹栈的节点，没有任何一条边能逃到 u 的祖先那里去！
而栈里位于 u 上方的那些节点，又全都通过子树/环路留在了这里（否则它们早就在自己的分支里满足 dfn == low 先弹出去了）。
所以此时从栈顶一直弹到 u 为止，弹出来的这批点恰好就是一个完整的强连通分量！

第 4 课 · 避坑指南 约 2 分钟

新手必看：三大易错点与时空复杂度

Tarjan 算法代码只有短短 20 行，但细节一错就会全盘 WA。这里帮你把最常踩的坑一次性标红。

1. 三大高频易错点

  • 坑 1：只从 1 号点调用 tarjan(1)。
    有向图极可能不连通，或者 1 号点根本没有出边！必须写循环： for (int i = 1; i <= n; i++) if (!dfn[i]) tarjan(i);
  • 坑 2：混用 dfn[v] 与 low[v]。
    在求强连通分量（SCC）时，碰到栈内节点 v 推荐写 low[u] = min(low[u], dfn[v])。虽然在 SCC 中写成 low[v] 侥幸也能对，但在求无向图割点 / 点双连通分量时写成 low[v] 会直接 WA！养成固定写 dfn[v] 的好习惯。
  • 坑 3：数组大小与自环/重边。
    自环（u → u）和重边不需要特判，Tarjan 天然能正确处理；但缩点建新图时记得把自环去掉（if (scc[u] != scc[v])），否则新图会多出多余自环影响拓扑排序入度！

2. 为什么时间复杂度能做到线性 O(V + E)？

  • 每个点最多被 tarjan() 访问 1 次，入栈 1 次，出栈 1 次。
  • 每条有向边最多在 for (int v : g[u]) 中被检查 1 次。
  • 因此总时间复杂度严格为 O(V + E)，空间复杂度为 O(V + E)，百万级点数也能毫秒级跑完！

第 5 课 · 实际应用 工程与竞赛高频场景

Tarjan SCC 在现实工程与算法中的四大应用

强连通分量绝不只是竞赛考题——编译器、包管理器、路由网络和逻辑求解器每天都在底层跑着 Tarjan 算法。

📦 1. 软件循环依赖检测 工程

大型项目或包管理器（npm / Maven / C++ 模块）中，如果模块 A 导入 B、B 导入 C、C 又导入 A，就会引发编译死锁或初始化崩溃。

建模：模块为点，依赖为有向边。所有大小 ≥ 2 的 SCC 就是全部循环依赖死锁环；缩点后的拓扑序就是合法构建顺序！

📣 2. 社交网络“核心圈层” 图分析

在微博/关注关系图里，若 A 关注 B 则连边 A → B，如何找出“被全网所有人（直接或间接）关注”的明星群体？

建模：缩点成 DAG 后，如果整个图恰好只有 1 个出度为 0 的 SCC，这个 SCC 里的所有人就是答案；若有多个则无解！

🧩 3. 2-SAT 布尔逻辑求解 约束求解

给定一堆二选一约束（如“要么选 A，要么不选 B”），判断是否存在一组满足所有条件的真假赋值方案。

建模：拆成蕴含边 ¬A → B 和 ¬B → A。若 x 与 ¬x 同属一个 SCC 则无解；否则直接取 Tarjan 编号较小的（scc[x] < scc[¬x]）！

🛣️ 4. 单向路网高可用改造 网络规划

城市单向交通网（或机房单向路由）目前不能全网互通，最少需要新建几条单向边才能让任意两点互达？

建模：缩点成 DAG（若只有 1 个 SCC 答案为 0）。统计缩点后入度为 0 的点数 P 和出度为 0 的点数 Q，答案就是 max(P, Q)！
一个隐藏彩蛋：Tarjan 算出的 scc[] 编号自带“逆拓扑序”！
由于先完成、先弹栈的总是处于有向图下游（没有出边或出边已走完）的分量，所以如果有边 SCC_a → SCC_b，必然先弹出 SCC_b 再弹出 SCC_a，即 scc[b] < scc[a]！做缩点 DP 时甚至不用再写一遍拓扑排序，直接按 cnt 倒序枚举即可！

第 6 课 · 学以致用 模板到综合

三道梯度经典实战题解（附可交 C++ 代码）

掌握原理和应用场景后，这三道由浅入深的洛谷经典题将帮你把 Tarjan SCC 彻底变成肌肉记忆。

题意：给定 n 个点 m 条边的有向图，输出强连通分量的个数，并按每个分量最小顶点编号从小到大的顺序，依次输出每个强连通分量的所有顶点。

思路：标准 Tarjan 模板题。跑完 tarjan() 后，把每个分量内部节点升序排序，再按各分量的最小节点编号排序输出即可。

Luogu_B3609_Tarjan_SCC.cpp（O(n log n + m)） 
#include <bits/stdc++.h>
using namespace std;

const int N = 10005;
vector<int> g[N];
int dfn[N], low[N], tim, stk[N], top;
bool ins[N];
vector<vector<int>> sccs;

void tarjan(int u) {
    dfn[u] = low[u] = ++tim;
    stk[++top] = u; ins[u] = true;
    for (int v : g[u]) {
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (ins[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (dfn[u] == low[u]) {
        vector<int> comp;
        int x;
        do {
            x = stk[top--]; ins[x] = false;
            comp.push_back(x);
        } while (x != u);
        sort(comp.begin(), comp.end());
        sccs.push_back(comp);
    }
}

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n, m; cin >> n >> m;
    while (m--) {
        int u, v; cin >> u >> v;
        g[u].push_back(v);
    }
    for (int i = 1; i <= n; i++) if (!dfn[i]) tarjan(i);
    sort(sccs.begin(), sccs.end());
    cout << sccs.size() << '\n';
    for (auto &c : sccs) {
        for (int i = 0; i < (int)c.size(); i++)
            cout << c[i] << (i + 1 == (int)c.size() ? '\n' : ' ');
    }
}

题意：给定一个点带权的有向图（允许重复经过点与边，但点权只累加一次），求一条路径使得经过的点权之和最大。

思路：因为可以重复走，只要进入一个 SCC 就一定能拿光该 SCC 的所有点权！用 Tarjan 把每个 SCC 缩成一个点（新点权 = 内部点权之和），得到 DAG 后，利用 Tarjan 编号自带的逆拓扑序直接做一遍线性 DP：dp[u] = val[u] + max(dp[v])。

Luogu_P3387_Condensation_DP.cpp（O(n + m)） 
#include <bits/stdc++.h>
using namespace std;

const int N = 10005;
vector<int> g[N], dag[N];
int a[N], dfn[N], low[N], tim, stk[N], top;
int scc[N], cnt, sumW[N], dp[N];
bool ins[N];

void tarjan(int u) {
    dfn[u] = low[u] = ++tim;
    stk[++top] = u; ins[u] = true;
    for (int v : g[u]) {
        if (!dfn[v]) { tarjan(v); low[u] = min(low[u], low[v]); }
        else if (ins[v]) low[u] = min(low[u], dfn[v]);
    }
    if (dfn[u] == low[u]) {
        ++cnt; int x;
        do {
            x = stk[top--]; ins[x] = false;
            scc[x] = cnt; sumW[cnt] += a[x];
        } while (x != u);
    }
}

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n, m; cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 0, u, v; i < m; i++) {
        cin >> u >> v; g[u].push_back(v);
    }
    for (int i = 1; i <= n; i++) if (!dfn[i]) tarjan(i);

    // 缩点建新 DAG
    for (int u = 1; u <= n; u++)
        for (int v : g[u])
            if (scc[u] != scc[v]) dag[scc[u]].push_back(scc[v]);

    // 逆拓扑序：1..cnt 本身就是从下游到上游，直接转移
    int ans = 0;
    for (int i = 1; i <= cnt; i++) {
        int best = 0;
        for (int nxt : dag[i]) best = max(best, dp[nxt]);
        dp[i] = sumW[i] + best;
        ans = max(ans, dp[i]);
    }
    cout << ans << '\n';
}

题意：N 头牛，给定若干单向“仰慕”关系（A → B 表示 A 认为 B 受欢迎，仰慕具有传递性）。求有多少头牛被除自己外的所有牛仰慕？

思路：缩点成 DAG 后，一头牛想被全图所有分量到达，它所在的 SCC 出度必须为 0；如果有 2 个及以上出度为 0 的 SCC，它们互相到不了对方，答案直接是 0；如果恰好只有 1 个出度为 0 的 SCC，答案就是该 SCC 的大小！

Luogu_P2341_Popular_Cows.cpp（O(n + m)） 
#include <bits/stdc++.h>
using namespace std;

const int N = 10005;
vector<int> g[N];
int dfn[N], low[N], tim, stk[N], top, scc[N], sz[N], outDeg[N], cnt;
bool ins[N];

void tarjan(int u) {
    dfn[u] = low[u] = ++tim;
    stk[++top] = u; ins[u] = true;
    for (int v : g[u]) {
        if (!dfn[v]) { tarjan(v); low[u] = min(low[u], low[v]); }
        else if (ins[v]) low[u] = min(low[u], dfn[v]);
    }
    if (dfn[u] == low[u]) {
        ++cnt; int x;
        do {
            x = stk[top--]; ins[x] = false;
            scc[x] = cnt; sz[cnt]++;
        } while (x != u);
    }
}

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n, m; cin >> n >> m;
    while (m--) {
        int u, v; cin >> u >> v;
        g[u].push_back(v);
    }
    for (int i = 1; i <= n; i++) if (!dfn[i]) tarjan(i);

    for (int u = 1; u <= n; u++)
        for (int v : g[u])
            if (scc[u] != scc[v]) outDeg[scc[u]]++;

    int zeroOut = 0, ans = 0;
    for (int i = 1; i <= cnt; i++) {
        if (outDeg[i] == 0) {
            zeroOut++;
            ans = sz[i];
        }
    }
    cout << (zeroOut == 1 ? ans : 0) << '\n';
}
