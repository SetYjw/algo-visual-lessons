暴力的瓶颈：如何一眼找到“下一个更大元素”？

一排人从左到右站队，每个人都向右看，想知道第一个比自己高的人站在几号位。如果每人挨个往右数，数据一大就会瞬间超时。

1. 经典问题：下一个更大元素（Next Greater Element）

给定长度为 n 的数组 a[1..n]，对每个下标 i，求它右侧第一个严格大于 a[i] 的元素下标 j（不存在则记为 0）。

  • 暴力写法：外层枚举 i，内层从 i + 1 往右扫描直到遇到第一个更大的数。最坏情况（数组严格递减）要做 n(n − 1) / 2 次比较，复杂度 O(n2)。
  • 现实瓶颈：在洛谷模板题 P5788 中，n ≤ 3 × 106，O(n2) 需要近 1013 次运算，直接 TLE！

2. 破局的瞬间：谁注定被“永远淘汰”？

核心直觉（淘汰法则）：
如果前面有个更矮且更早的人被你挡住了，它永远不可能成为后面任何人的答案——直接淘汰！
换个角度从左往右看：当身高为 5 的人入场时，前面还在苦苦等待的 1 和 2 瞬间找到了答案（就是 5！），它们任务完成，立刻出局，后面的人再也不用回头看它们了。
当更大的数 5 到来时，前面比它矮的 1、2 立刻结算答案并出栈，绝不拖泥带水

第 2 课 · 核心机制与复杂度 约 4 分钟

单调栈核心与严格 O(n) 势能证明

把“还没找到答案的人”放进一个栈 stk 里。为了保证不被跳过，栈里从底到顶的身高天然保持单调不增（单调递减）！

1. 为什么栈里存的是“下标”而不是“数值”？

  • 我们最终要填写 ans[stk.top()] = i，必须知道被弹出元素原来的位置下标。
  • 有了下标 idx，随时可以通过 a[idx] 拿到数值，还能计算距离 i − idx，一举两得！

2. 核心 4 行模板（从左到右扫描）

while (!stk.empty() && a[i] > a[stk.top()]) { ans[stk.top()] = i; stk.pop(); }
stk.push(i);

维护不变式：每当新元素 a[i] 进栈前，所有比它严格小的栈顶都会被弹走。因此压入 i 之后，栈从底到顶必然满足 a[stk[0]] ≥ a[stk[1]] ≥ ... ≥ a[stk.top()]。

3. 新手最疑惑：for 里面套 while，为什么不是 O(n2)？

势能 / 摊还分析（一句话秒懂）：
盯着每一个下标 k 的一生：它在整个算法中最多入栈 1 次（在 i = k 时），也最多出栈 1 次（一旦被弹出就永不回头）！
因此所有 while 循环加起来的总弹出次数绝不会超过 n 次，总栈操作次数满足：
总入栈 + 总出栈 ≤ 2n ⇒ 严格线性时间 O(n)！

4. 一张表掌握单调栈四大变形

查询目标栈内单调性（底 → 顶）弹栈条件
右侧第一个更大单调递减（不增）a[i] > a[stk.top()]
右侧第一个更小单调递增（不减）a[i] < a[stk.top()]
左侧第一个更大单调递减（不增）a[stk.top()] ≤ a[i] 弹出，新栈顶即答案
左侧第一个更小单调递增（不减）a[stk.top()] ≥ a[i] 弹出，新栈顶即答案

第 3 课 · 经典变形 约 4 分钟

一趟扫描定左右边界：柱状图最大矩形与接雨水

单调栈最惊艳的技巧在于：当元素 mid 被弹出的那一瞬间，它左边和右边的第一个“挡板”竟然同时现身了！

1. 柱状图中最大的矩形（LeetCode 84）

枚举每根柱子 mid 作为矩形的高度 h[mid]，它最多能向左延伸到“左边第一个比它矮的柱子 L”，向右延伸到“右边第一个比它矮的柱子 R”。

  • 维护一个单调递增栈。当新柱子 h[i] < h[stk.top()] 时，弹出栈顶 mid：
  • 右边界 R = i（正是它把 mid 弹出来的！）；
  • 左边界 L = stk.top()（弹完 mid 后的新栈顶，因为栈递增，它就是左边第一个比 h[mid] 矮的柱子！）。
  • 矩形面积：h[mid] × (R − L − 1)。在数组头尾各加一个高度为 0 的哨兵，就能省去所有判空和收尾特判！
当柱子 5 被右侧更矮的 2 弹出时，新栈顶 1 是左边界，2 是右边界，最大矩形 5 × 2 = 10 瞬间算出

2. 接雨水（LeetCode 42）——按“行”横向蓄水

反过来，维护一个单调递减栈！当新柱子 h[i] > h[stk.top()] 时，说明右侧出现了一堵高墙，形成了一个“凹槽”：

  • 弹出栈顶 mid 作为凹槽底部；
  • 如果栈非空，新的栈顶 left = stk.top() 就是左墙，当前 i 是右墙；
  • 这一层能接住的雨水面积 = (min(h[left], h[i]) − h[mid]) × (i − left − 1)。

第 4 课 · 双端队列升级 约 4 分钟

单调队列：O(1) 拿下滑动窗口最大值

如果题目要求维护长度为 k 的滑动窗口 [i − k + 1, i] 内的最大值，光靠栈就不够了——因为左边的老元素会“过期滑出窗口”！

1. 为什么栈不够，需要双端队列 deque？

在滑动窗口中，候选冠军面临两种淘汰：

  1. 队头过期淘汰（出界了）：如果队头下标 dq.front() ≤ i − k，说明它已经掉出当前窗口，必须从队头弹出 dq.pop_front()。
  2. 队尾能力淘汰（又老又弱）：如果队尾元素 a[dq.back()] ≤ a[i]，它既比新来的 i 小、又比 i 更早过期，永无出头之日，直接从队尾踢走 dq.pop_back()！
1. 队头去过期：while (!dq.empty() && dq.front() ≤ i - k) dq.pop_front();
2. 队尾去更弱：while (!dq.empty() && a[dq.back()] ≤ a[i]) dq.pop_back();
3. 新人进队尾：dq.push_back(i);    4. 队头即答案：ans[i] = a[dq.front()];
队头为什么一定是窗口最大值？
经过上述维护，双端队列从头到尾的下标严格递增（都没过期），对应的数值严格递减。所以 dq.front() 永远是当前窗口里的绝对老大，查询只需 O(1)！且每个元素依然最多入队 1 次、出队 1 次，总时间严格 O(n)。

第 5 课 · 工程与算法建模 约 3 分钟

单调栈与单调队列的四大真实应用场景

看似简单的“维护单调性”，在金融量化、运维监控、图形排版与动态规划加速中无处不在。

1. 股票价格跨度与回撤周期 单调栈

量化看板需要实时计算“今天股价连续多少天高于或等于此前价格”（Online Stock Span，LeetCode 901）。

建模：维护单调递减栈，弹出所有 ≤ 今日股价 的历史记录并累加其跨度，每个交易日摊还 O(1) 完成。

2. 实时流数据滑动窗口峰值监控 单调队列

网关限流、Prometheus / APM 监控需要每秒汇报“最近 60 秒内的最大延迟或最高 QPS 峰值”。

建模：用单调递减双端队列缓存 (timestamp, value)，队头按时间窗口过期，队尾淘汰低峰，每条日志 O(1) 实时出峰值。

3. 图像处理与布局引擎最大空白矩形 单调栈

在 OCR 版面分析、广告位排布或二值掩码图中，寻找面积最大的连续可用空白矩形（LeetCode 85）。

建模：逐行向上累加连续空白高度，把二维矩阵拆成 R 个柱状图，每行跑一遍单调递增栈，总耗时 O(R × C)。

4. DP 转移优化：多重背包与区间 DP 单调队列

当状态转移形如 dp[i] = max(dp[j] + w) 且决策点 j 落在固定长度滑窗内时，直接转移需 O(nk)。

建模：用单调队列维护滑窗内最优决策点 j，将多重背包或定长子段和 DP 的复杂度直接压低一维至 O(n)！

第 6 课 · 竞赛与面试实战 3 道梯度精讲

梯度实战题解（可直接提交的 C++ 模板）

从洛谷两大核心模板题，到面试高频压轴题 LeetCode 84，点击标签切换题解，并可一键把样例送到右侧动画台逐步验证。

题意：给定长度为 n（n ≤ 3 × 106）的数列 a[1..n]，求每个元素之后第一个严格大于它的元素下标，不存在则输出 0。

建模思路：维护单调递减栈存下标。每扫到 a[i]，只要栈非空且 a[i] > a[stk.top()]，就记录 ans[stk.top()] = i 并弹栈，最后把 i 压栈。手写数组栈在 3 × 106 数据下速度更快。

Luogu_P5788_Monotonic_Stack.cpp（时间 O(n)） 
#include <bits/stdc++.h>
using namespace std;

const int N = 3000005;
int a[N], ans[N], stk[N], top;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];

    for (int i = 1; i <= n; i++) {
        while (top > 0 && a[i] > a[stk[top]]) {
            ans[stk[top]] = i;
            top--;
        }
        stk[++top] = i;
    }
    for (int i = 1; i <= n; i++)
        cout << ans[i] << (i == n ? '\n' : ' ');
    return 0;
}

题意：给定长度为 n 的数组和窗口大小 k，窗口每次向右滑动 1 格，输出每个窗口内的最大值（洛谷 P1886 额外要求先输出最小值，把队尾比较符号取反即可）。

建模思路：使用双端队列 deque<int> dq 存下标：先踢掉队头过期下标（dq.front() ≤ i − k），再踢掉队尾所有 ≤ a[i] 的弱元素，压入 i，当 i ≥ k 时输出 a[dq.front()]。

Luogu_P1886_LC239_Sliding_Window.cpp（时间 O(n)） 
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<int> a(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i];

    deque<int> dq; // 单调递减队列，队头为当前窗口最大值下标
    for (int i = 1; i <= n; i++) {
        while (!dq.empty() && dq.front() <= i - k)
            dq.pop_front();
        while (!dq.empty() && a[dq.back()] <= a[i])
            dq.pop_back();
        dq.push_back(i);
        if (i >= k)
            cout << a[dq.front()] << (i == n ? '\n' : ' ');
    }
    return 0;
}

题意：给定 n 个非负整数表示柱状图中各个柱子的高度（每根柱子宽度为 1），求柱状图中能够勾勒出来的最大矩形面积。

建模思路：在数组首尾各加一个高度为 0 的哨兵，维护单调递增栈。每当遇到 h[i] < h[stk.top()]，弹出栈顶 mid，此时右边界为 i，左边界为新栈顶 stk.top()，面积直接更新为 h[mid] × (i − stk.top() − 1)。

LeetCode_84_Largest_Rectangle.cpp（时间 O(n)） 
#include <bits/stdc++.h>
using namespace std;

int largestRectangleArea(vector<int> h) {
    // 首尾各加高度为 0 的哨兵：左哨兵防栈空，右哨兵强制清空所有柱子
    h.insert(h.begin(), 0);
    h.push_back(0);
    stack<int> stk;
    stk.push(0);
    int ans = 0;

    for (int i = 1; i < (int)h.size(); i++) {
        while (h[i] < h[stk.top()]) {
            int mid = stk.top();
            stk.pop();
            int width = i - stk.top() - 1;
            ans = max(ans, h[mid] * width);
        }
        stk.push(i);
    }
    return ans;
}
