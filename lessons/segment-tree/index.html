为什么我们需要线段树？

当一个长度为 105 的数组，既要频繁修改某一段区间，又要频繁查询任意区间的和或最值时，普通数组和前缀和都会彻底卡死。

1. 四种方案横向对比

假设数组长度为 n，有 q 次操作（例如 n = 105, q = 105）：

数据结构 单点修改 区间修改 区间查询 适用范围
暴力数组 O(1) O(n) O(n) 数据极小，查询一多直接 TLE
前缀和 O(n) O(n) O(1) 仅限静态数组，一修改全崩
树状数组 (BIT) O(log n) O(log n)* O(log n) 适合可减信息（如区间和），难维护区间最值/复杂合并
线段树 (Segment Tree) O(log n) O(log n) O(log n) 全能王者：区间和、最值、GCD、区间乘加、扫描线等

* 注：树状数组需配合差分才能做区间加，但面对“区间赋值”“区间乘加”“动态区间最大值”等操作就无能为力了。

2. 核心思想：像公司组织一样“分治汇报”

为什么暴力查询慢？因为每次都要把区间的每个元素挨个加一遍。线段树的思路极其朴素：把大区间不断一分为二，提前算好每一段的汇总值！

  • 基层员工（叶子节点）：负责单个元素 [i, i]，保存 a[i]。
  • 各级主管（内部节点）：负责一段连续区间 [l, r]，只保存左半主管 [l, mid] 和右半主管 [mid+1, r] 的汇总结果。
  • 查询时：只要某个主管管辖的范围完全落在目标区间内，直接拿他的汇总报表走人，绝不惊动他底下的员工！
每个节点保存其负责区间的汇总值，整棵树高度仅为 ⌈log2 n⌉ + 1

第 2 课 · 存储与建树 约 4 分钟

建树、堆式编号与为什么数组要开 4n？

写线段树并不需要复杂的指针和 new Node，只用一个普通一维数组 tr[] 就能以极高效率存下整棵树！

1. 区间二分与堆式编号

根节点编号固定为 p = 1，负责区间 [1, n]。对于任意非叶子节点 p（负责 [l, r]）：

mid = (l + r) >> 1
左儿子：编号 2p (p << 1)，负责 [l, mid]
右儿子：编号 2p + 1 (p << 1 | 1)，负责 [mid + 1, r]

2. pushUp：汇总左右儿子的结果

建树 build(p, l, r) 就是一个标准的后序遍历：

  1. 如果 l == r，到达叶子，直接赋值 tr[p] = a[l] 返回。
  2. 否则先递归建左子树 build(2*p, l, mid)，再建右子树 build(2*p+1, mid+1, r)。
  3. 两棵子树都建好后，执行 pushUp：tr[p] = tr[2*p] + tr[2*p+1]。

3. 经典面试/竞赛必问：为什么 tr[] 要开 4 × n？

一棵有 n 个叶子的满二叉树总共才 2n − 1 个节点，为什么开 2 * n 会数组越界（RE）？

关键原因：堆式编号在最后一层会有“空洞”！
当 n 不是 2 的幂（例如 n = 6 或 n = 10）时，树不是完全二叉树，某些叶子落在了更深的一层。最坏情况下，倒数第二层有接近 n 个节点，最后一层最靠右的叶子编号可能接近 4n！所以竞赛标准写法一律开 4 * MAXN，稳如泰山。

第 3 课 · O(log n) 查询 约 3 分钟

区间查询的 O(log n) 奇迹：拼图与剪枝

无论查询区间 [ql, qr] 有多长，线段树总能把它拆成不超过 2 log2 n 块完整拼图，绝不逐个访问叶子。

1. 查询时的三种相遇关系

假设当前递归到了节点 p（负责 [l, r]），目标是查询 [ql, qr]：

  • 完全覆盖 若 ql ≤ l && r ≤ qr：整个节点都在查询范围内，直接返回 tr[p]，绝不继续往下递归！
  • 部分重叠 否则先算 mid = (l + r) >> 1：
    • 如果 ql ≤ mid，说明左半 [l, mid] 与查询区间有交集，递归查左儿子；
    • 如果 qr > mid，说明右半 [mid+1, r] 与查询区间有交集，递归查右儿子。
  • 完全无交（剪枝） 不满足上述条件的分支根本不进入，直接跳过！

2. 为什么复杂度严格是 O(log n)？

每一层中，只有在查询区间左端点 ql 和右端点 qr 所在的边界处，节点才会被“劈开继续往下查”；中间夹着的所有节点都会触发“完全覆盖”立刻返回。因此每层最多访问 4 个节点，总访问节点数 ≤ 4 ⌈log2 n⌉ = O(log n)！

第 4 课 · 灵魂核心 约 5 分钟

灵魂机制：懒标记（Lazy Tag）与 pushDown

如果要把区间 [2, 100000] 的每个数都加 3，老老实实改到每个叶子会退化成 O(n)。懒标记用“先记账、用到再结算”的天才思路，把区间修改硬生生压回 O(log n)！

1. 生活类比：先打欠条，查账时再发钱

老板宣布：“给 2~5 号员工每人发 3 元奖金。”

  • 笨办法（无懒标记）：财务挨个敲门把钱送到 2、3、4、5 号员工手里——人一多就跑断腿（O(n)）。
  • 聪明办法（懒标记 lz[p]）：找到完全管辖 [3, 4] 的主管，把他的部门总账直接加 3 × 2 = 6，再在他头上贴一张琥珀色便利贴 lz[p] += 3（意思是：“欠手下每人 3 块钱，先别发”），然后直接收工！

2. 何时结算？pushDown(p, l, r)

只要以后没人追问 [3, 4] 里面单独某个人的钱，这张欠条就可以一直贴着！直到某次查询或修改必须拆开进入 p 的左右儿子之前，先调用 pushDown(p, l, r) 把账结给两个儿子：

tr[2p] += lz[p] × (mid - l + 1);   lz[2p] += lz[p];
tr[2p+1] += lz[p] × (r - mid);      lz[2p+1] += lz[p];
lz[p] = 0;  // 自己的欠条已还清，务必清零！
新手四大高频踩坑清单：
  • 更新区间和时忘了乘区间长度 (r - l + 1)。
  • 在 query 或 modify 向下递归前忘了调用 pushDown。
  • 下传完后忘了把 lz[p] = 0（导致重复加钱！）。
  • 区间和与增量乘积容易爆 int，竞赛题几乎一律开 long long！

线段树在真实世界能干什么？

只要业务数据可以按时间、坐标或编号排成一维序列，并且需要动态区间统计或调度，背后往往都有线段树的身影。

🎮 游戏实时积分榜与区间统计 区间和

活动期间要给排名在 [L, R] 的玩家批量发放积分奖励，并实时查询某段位区间的总积分或第 k 名玩家。

建模：下标为段位/积分桶，值域线段树支持 O(log V) 查排名与区间汇总。

📈 金融 K 线历史区间最高/最低价 RMQ

量化系统每秒接收新成交价，前端拖拽任意时间窗口 [t1, t2] 时，瞬间返回该段最高价、最低价与成交总量。

建模：每个节点同时维护 (maxP, minP, sumVol)，新 K 线到来时单点更新 O(log n)。

🏢 机房/会议室区间资源动态调度 懒标记

云集群或日程系统需判断时间段 [s, t] 内服务器峰值负载是否超限，若未超限则将该时段负载整体 +c。

建模：线段树维护区间最大值 + 区间加懒标记，先查 queryMax(s, t) 再执行 add(s, t, +c)。

📐 图形学扫描线求矩形面积并 扫描线

芯片布线、地图渲染或 CAD 中，计算成千上万个重叠矩形覆盖的总面积，避免像素级暴力枚举。

建模：按 x 坐标从左到右扫描，用线段树维护 y 轴上被覆盖的总长度 len[1]，总耗时 O(n log n)。

LeetCode 307. 区域和检索 - 数组可修改

题意：给定整数数组 nums，支持 update(index, val) 单点修改与 sumRange(left, right) 区间求和，操作数达 3 × 104。

思路：因为只有单点修改，不需要懒标记！写好 build、modify 和 query 三个短函数即可（注意 LeetCode 输入为 0 下标，转成 1 下标更不易错）。

C++ · 单点修改 + 区间查询（无懒标） 
class NumArray {
    int n;
    vector<int> tr;

    void build(int p, int l, int r, const vector<int>& a) {
        if (l == r) { tr[p] = a[l - 1]; return; }
        int mid = (l + r) >> 1;
        build(p << 1, l, mid, a);
        build(p << 1 | 1, mid + 1, r, a);
        tr[p] = tr[p << 1] + tr[p << 1 | 1];
    }

    void modify(int p, int l, int r, int x, int v) {
        if (l == r) { tr[p] = v; return; }
        int mid = (l + r) >> 1;
        if (x <= mid) modify(p << 1, l, mid, x, v);
        else          modify(p << 1 | 1, mid + 1, r, x, v);
        tr[p] = tr[p << 1] + tr[p << 1 | 1];
    }

    int query(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tr[p];
        int mid = (l + r) >> 1, res = 0;
        if (ql <= mid) res += query(p << 1, l, mid, ql, qr);
        if (qr > mid)  res += query(p << 1 | 1, mid + 1, r, ql, qr);
        return res;
    }

public:
    NumArray(vector<int>& nums) : n(nums.size()), tr(4 * n + 5, 0) {
        if (n > 0) build(1, 1, n, nums);
    }
    void update(int index, int val) { modify(1, 1, n, index + 1, val); }
    int sumRange(int left, int right) { return query(1, 1, n, left + 1, right + 1); }
};

洛谷 P3372 【模板】线段树 1

题意：给定长度为 n (≤ 105) 的序列，支持两种操作：① 将区间 [x, y] 内每个数加上 k；② 输出区间 [x, y] 内每个数的和。

思路：最经典的带懒标记线段树标准模板！与右侧演示台的算法完全一致，务必全部使用 long long 防止溢出。

C++ · 洛谷 P3372 标准 AC 模板（long long + Lazy Tag） 
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int MAXN = 100005;
ll a[MAXN], tr[MAXN * 4], lz[MAXN * 4];

void pushUp(int p) { tr[p] = tr[p << 1] + tr[p << 1 | 1]; }

void build(int p, int l, int r) {
    if (l == r) { tr[p] = a[l]; return; }
    int mid = (l + r) >> 1;
    build(p << 1, l, mid);
    build(p << 1 | 1, mid + 1, r);
    pushUp(p);
}

void pushDown(int p, int l, int r) {
    if (!lz[p]) return;
    int mid = (l + r) >> 1;
    tr[p << 1]     += lz[p] * (mid - l + 1);
    lz[p << 1]     += lz[p];
    tr[p << 1 | 1] += lz[p] * (r - mid);
    lz[p << 1 | 1] += lz[p];
    lz[p] = 0;
}

void update(int p, int l, int r, int ql, int qr, ll v) {
    if (ql <= l && r <= qr) {
        tr[p] += v * (r - l + 1);
        lz[p] += v;
        return;
    }
    pushDown(p, l, r);
    int mid = (l + r) >> 1;
    if (ql <= mid) update(p << 1, l, mid, ql, qr, v);
    if (qr > mid)  update(p << 1 | 1, mid + 1, r, ql, qr, v);
    pushUp(p);
}

ll query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return tr[p];
    pushDown(p, l, r);
    int mid = (l + r) >> 1;
    ll res = 0;
    if (ql <= mid) res += query(p << 1, l, mid, ql, qr);
    if (qr > mid)  res += query(p << 1 | 1, mid + 1, r, ql, qr);
    return res;
}

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n, m; cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];
    build(1, 1, n);
    while (m--) {
        int op, x, y; cin >> op >> x >> y;
        if (op == 1) { ll k; cin >> k; update(1, 1, n, x, y, k); }
        else cout << query(1, 1, n, x, y) << '\n';
    }
}

洛谷 P3373 【模板】线段树 2（先乘后加双懒标）

题意：同时支持 ① 区间乘 k、② 区间加 k、③ 区间求和（对 mod 取模）。

核心秘诀：规定“先乘后加”的仿射变换！每个节点维护两个懒标 mul[p]（初值为 1）和 add[p]（初值为 0），代表对子树元素执行 x ← x × mul + add。执行区间乘 k 时，必须把已有的 add[p] 也乘上 k，这样下传时只需统一套用同一条公式！

C++ · 洛谷 P3373 双懒标记（先乘后加） 
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int MAXN = 100005;
ll a[MAXN], tr[MAXN * 4], mul[MAXN * 4], addv[MAXN * 4], MOD;

void apply(int p, int len, ll m, ll ad) {
    tr[p]   = (tr[p] * m + ad * len) % MOD;
    mul[p]  = mul[p] * m % MOD;
    addv[p] = (addv[p] * m + ad) % MOD; // 关键：旧加法也要乘上新乘法！
}

void pushDown(int p, int l, int r) {
    if (mul[p] == 1 && addv[p] == 0) return;
    int mid = (l + r) >> 1;
    apply(p << 1,     mid - l + 1, mul[p], addv[p]);
    apply(p << 1 | 1, r - mid,     mul[p], addv[p]);
    mul[p] = 1; addv[p] = 0;
}

void build(int p, int l, int r) {
    mul[p] = 1; addv[p] = 0;
    if (l == r) { tr[p] = a[l] % MOD; return; }
    int mid = (l + r) >> 1;
    build(p << 1, l, mid);
    build(p << 1 | 1, mid + 1, r);
    tr[p] = (tr[p << 1] + tr[p << 1 | 1]) % MOD;
}

void update(int p, int l, int r, int ql, int qr, ll m, ll ad) {
    if (ql <= l && r <= qr) { apply(p, r - l + 1, m, ad); return; }
    pushDown(p, l, r);
    int mid = (l + r) >> 1;
    if (ql <= mid) update(p << 1, l, mid, ql, qr, m, ad);
    if (qr > mid)  update(p << 1 | 1, mid + 1, r, ql, qr, m, ad);
    tr[p] = (tr[p << 1] + tr[p << 1 | 1]) % MOD;
}

ll query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return tr[p];
    pushDown(p, l, r);
    int mid = (l + r) >> 1;
    ll res = 0;
    if (ql <= mid) res = (res + query(p << 1, l, mid, ql, qr)) % MOD;
    if (qr > mid)  res = (res + query(p << 1 | 1, mid + 1, r, ql, qr)) % MOD;
    return res;
}

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n, q; cin >> n >> q >> MOD;
    for (int i = 1; i <= n; i++) cin >> a[i];
    build(1, 1, n);
    while (q--) {
        int op, x, y; cin >> op >> x >> y;
        if (op == 1) { ll k; cin >> k; update(1, 1, n, x, y, k % MOD, 0); }
        else if (op == 2) { ll k; cin >> k; update(1, 1, n, x, y, 1, k % MOD); }
        else cout << query(1, 1, n, x, y) << '\n';
    }
}
