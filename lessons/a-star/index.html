第 1 课 · 动机与直觉 约 3 分钟

为什么 Dijkstra / BFS 寻路像“无头苍蝇”？

假设你在北京，要开车去上海（东南方向）。你会先往西北方向的乌鲁木齐开 1000 公里看看路通不通吗？Dijkstra 就会！

1. 盲目搜索的代价：水波纹式扩散

无论是无权图的 BFS，还是带权图的 Dijkstra，它们都只关心“从起点 S 已经走了多远”，而对“终点 T 在哪个方向”一无所知。

  • 结果就是：算法以起点为圆心，像往池塘里扔石头激起的水波纹一样，向四面八方均匀扩张。
  • 在 1000 × 1000 的游戏大地图里，即使终点就在正前方，Dijkstra 也会把起点背后、上下左右几十万个明显背道而驰的格子全部搜索一遍！

2. A* 的直觉：给搜索装上“指南针”

A*（A-Star）算法的核心思想非常朴素：在决定下一步先探索哪个格子时，不仅看已经走了多远，还要结合“指南针”估算离终点大概还有多远，优先朝靠近终点的方向探索！

对比：Dijkstra 盲目向外铺开水波纹，A* 则在启发函数引导下直奔目标

第 2 课 · 核心机制 约 4 分钟

灵魂公式：估价函数 f(n) = g(n) + h(n)

A* 算法并不神秘——它本质上就是把 Dijkstra 优先队列的排序关键字从 g(n) 改成了 f(n) = g(n) + h(n)。

f(n) = g(n) + h(n)

1. 三个字母分别代表什么？

  • g(n)（已付出的真实代价）：从起点 S 沿着当前路径走到节点 n 的精确开销（和 Dijkstra 里的 dist[n] 完全一样）。
  • h(n)（启发函数 / 乐观预估）：从节点 n 到终点 T 的预计剩余代价（Heuristic）。它不需要知道墙在哪，直接按几何距离算！
  • f(n)（总估价）：如果经过节点 n 到达终点，预计全程总代价是多少。优先队列每次总是弹出 f(n) 最小的节点来扩展！

2. 网格地图最常用的 3 种启发函数 h(n)

设当前格坐标为 (x1, y1)，终点为 (x2, y2)，令 dx = |x1 − x2|，dy = |y1 − y2|：

启发函数数学公式适用移动方式
曼哈顿距离 h = dx + dy 只能上下左右 4 方向移动（最经典）
欧几里得距离 h = √(dx2 + dy2) 允许任意角度自由移动（如导航网格）
切比雪夫 / 八角距离 max(dx, dy) 或 (dx+dy)+(√2−2)min(dx,dy) 允许8 方向（含对角线，代价 1 或 √2）
数据结构视角：A* 维护两个集合：Open 集合（最小堆，存放“已发现但尚未扩展”的候选格子）与 Closed 集合（布尔数组，存放“已经确定扩展过”的格子）。每次从 Open 堆顶取出 f 最小的格子，松弛它的邻居并放入 Open！

第 3 课 · 核心理论 约 4 分钟

为什么 A* 一定能找到最短路？——可采纳性证明

既然 h(n) 只是“猜的”，万一猜错了把真正的好路漏掉了怎么办？答案藏在一条黄金铁律里：宁可低估，绝不高估！

1. 黄金条件：可采纳性（Admissibility）

设 h*(n) 为节点 n 到终点 T 的真实最短距离。如果对于图中任意节点 n，启发函数都满足：

0 ≤ h(n) ≤ h*(n)   （永远不“高估”剩余路程）

我们就称 h(n) 是可采纳的（Admissible）。例如在每步代价 ≥ 1 的 4 方向网格中，曼哈顿距离是“没有任何障碍且每步都是最低代价 1”时的理想距离，因此绝不可能超过真实最短路，天然可采纳！

2. 反证法：3 行证明 A* 首次弹出终点即最优

设真实最短路代价为 C*。假设 A* 第一次从堆顶弹出终点 T 时，找到的却是一条更差的路径，代价 g(T) > C*：

  1. 此时真正最短路径上，必然还存在至少一个仍在 Open 集合里的节点 u（因为起点进过 Open，终点刚出堆）。
  2. 因为 u 在最短路上，且 h 可采纳，所以：
    f(u) = g(u) + h(u) ≤ g*(u) + h*(u) = C*。
  3. 由于 h(T) = 0，终点出堆时的优先级 f(T) = g(T) > C* ≥ f(u)。最小堆怎么可能先弹出更大的 f(T) 而把更小的 f(u) 留在堆里？矛盾！

3. 反面教材：高估 h(n) 会掉进什么坑？

如果我们把启发权重放大，比如用 Weighted A*（f = g + 2h） 或直接忽略 g 的贪心 BFS，它就会过度迷信直线方向——哪怕前方是一大片代价 = 3 的泥潭，它也会一头扎进去，错过旁边绕行代价更低的好路！

进阶概念 · 一致性（Consistency）：若对任意边 u → v 满足 h(u) ≤ cost(u, v) + h(v)（类似三角形两边之和大于第三边），则每个节点首次出堆时 g(u) 就已经最优，无需二次入队；一般只需可采纳性就能保证终点最优。

第 4 课 · 横向对比与避坑 约 3 分钟

一张公式统领四种寻路算法 + 工程避坑清单

其实 Dijkstra、贪心最佳优先搜索、A*、Weighted A* 是一家人——它们只是 f(n) = w1g(n) + w2h(n) 的不同特例！

1. 四大寻路算法全家福对比

算法优先级公式是否保证最优搜索行为特征
Dijkstra f = g（即 h = 0） 保证最优 水波纹均匀扩散，扩展节点最多，稳但慢
贪心 BFS f = h（即 g = 0） 不保证 只看终点狂冲，无障碍极快，遇 U 形墙或泥潭极易走弯路
标准 A* f = g + h（h ≤ h*） 保证最优 兼顾已走代价与终点方向，在保证最优下扩展节点最少
Weighted A* f = g + w·h（w > 1） ≤ w · 最优 用“最多差 w 倍”换取极快速度，大型游戏与机器人常用

2. 写 A* 最容易踩的 3 个实战坑

坑 1：堆里存在“过期旧条目”没跳过！
C++ 的 priority_queue 不支持直接修改堆内元素，松弛到更小的 g[v] 时会再次 push。出队时必须加一句 if (cur.g > g[u]) continue;（或判 closed[u]），否则会重复扩展导致 TLE！
坑 2：同 f 值平局（Tie-Breaking）导致多搜一片！
在空旷网格中，很多格子具有完全相同的 f = g + h。如果平局时优先选 h 更小（即 g 更大、更靠近终点） 的节点，就能直穿空地而不用把整个矩形全搜一遍！
坑 3：8 方向寻路时的“穿墙角”（Corner Cutting）
允许走对角线时，若 (r, c+1) 和 (r+1, c) 都是墙，不能直接斜穿到 (r+1, c+1)，否则游戏角色会卡进墙角缝隙。

第 6 课 · 学以致用 模板到竞赛

三道梯度经典实战题解（附可交 C++ 代码）

从最常用的二维网格模板，到状态空间搜索八数码，再到竞赛经典 K 短路——彻底把 A* 变成你的得分利器。

题意：给定 N × M 的二维网格（. 表示空地代价 1，~ 表示泥潭代价 3，# 表示障碍），求起点 S 到终点 T 的最小代价路径。

思路：由于每步最小代价为 1，直接取曼哈顿距离 h = |r-tr| + |c-tc| 即可保证可采纳性。使用小根堆维护 (f, h, g, r, c)（平局时优先 h 更小），出队判过期即可。

Grid_AStar_Template.cpp（支持障碍与加权地形） 
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int f, h, g, r, c;
    bool operator>(const Node& o) const {
        if (f != o.f) return f > o.f;
        return h > o.h; // Tie-breaking: 同 f 优先 h 更小
    }
};

int astarGrid(const vector<string>& mp, int sr, int sc, int tr, int tc) {
    int R = mp.size(), C = mp[0].size();
    const int INF = 1e9;
    vector<vector<int>> dist(R, vector<int>(C, INF));
    auto H = [&](int r, int c) { return abs(r - tr) + abs(c - tc); };

    priority_queue<Node, vector<Node>, greater<Node>> pq;
    dist[sr][sc] = 0;
    pq.push({H(sr, sc), H(sr, sc), 0, sr, sc});

    const int dr[4] = {-1, 1, 0, 0}, dc[4] = {0, 0, -1, 1};
    while (!pq.empty()) {
        auto cur = pq.top(); pq.pop();
        if (cur.g > dist[cur.r][cur.c]) continue; // 跳过过期条目
        if (cur.r == tr && cur.c == tc) return cur.g;

        for (int d = 0; d < 4; d++) {
            int nr = cur.r + dr[d], nc = cur.c + dc[d];
            if (nr < 0 || nr >= R || nc < 0 || nc >= C || mp[nr][nc] == '#') continue;
            int w = (mp[nr][nc] == '~') ? 3 : 1;
            int ng = cur.g + w;
            if (ng < dist[nr][nc]) {
                dist[nr][nc] = ng;
                int nh = H(nr, nc);
                pq.push({ng + nh, nh, ng, nr, nc});
            }
        }
    }
    return -1; // 不可达
}

题意（洛谷 P1379）：给定 3×3 棋盘的初始状态（数字 1~8 和空格 0），每次可将空格与相邻数字交换，求到达目标态 123804765 的最少步数。

思路：把 9 位字符串视作状态图中的点。估价函数 h(s) 取数字 1~8 当前坐标到目标坐标的曼哈顿距离之和（严格可采纳）。相比普通 BFS 扩展上万状态，A* 通常只扩展几十到几百个状态！

Luogu_P1379_EightPuzzle_AStar.cpp 
#include <bits/stdc++.h>
using namespace std;

const string TARGET = "123804765";
int tx[9], ty[9];

int calcH(const string& s) {
    int h = 0;
    for (int i = 0; i < 9; i++) {
        int d = s[i] - '0';
        if (d != 0) h += abs(i / 3 - tx[d]) + abs(i % 3 - ty[d]);
    }
    return h;
}

int main() {
    for (int i = 0; i < 9; i++) { tx[TARGET[i] - '0'] = i / 3; ty[TARGET[i] - '0'] = i % 3; }
    string st; cin >> st;

    using State = pair<int, string>;
    priority_queue<State, vector<State>, greater<State>> pq;
    unordered_map<string, int> dist;
    dist[st] = 0;
    pq.push({calcH(st), st});

    const int dx[4] = {-1, 1, 0, 0}, dy[4] = {0, 0, -1, 1};
    while (!pq.empty()) {
        auto [f, u] = pq.top(); pq.pop();
        int g = dist[u];
        if (u == TARGET) { cout << g << '\n'; return 0; }
        if (f > g + calcH(u)) continue;

        int pos = u.find('0'), x = pos / 3, y = pos % 3;
        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d], ny = y + dy[d];
            if (nx < 0 || nx >= 3 || ny < 0 || ny >= 3) continue;
            string v = u; swap(v[pos], v[nx * 3 + ny]);
            if (!dist.count(v) || g + 1 < dist[v]) {
                dist[v] = g + 1;
                pq.push({g + 1 + calcH(v), v});
            }
        }
    }
}

题意（经典 K 短路 / 洛谷 P2483 思路）：给定有向正权图，求从起点 S 到终点 T 的第 K 短路径长度（允许重复经过点与边）。

神级建模：先在反图上从 T 跑一遍 Dijkstra，算出每个点到 T 的精确最短距离 h[u] = dist_rev[u]！这是最完美的启发函数（h = h*）。随后从 S 跑 A*（不做 closed 限制），第 K 次从堆顶弹出终点 T 时的 g 值，就是严格的第 K 短路！

Kth_Shortest_Path_AStar.cpp（反向 Dijkstra + A*） 
#include <bits/stdc++.h>
using namespace std;

const int N = 5005;
const double INF = 1e18;
vector<pair<int, double>> g[N], rg[N];
double h[N];
int cnt[N];

void dijkstraRev(int n, int T) {
    fill(h, h + n + 1, INF);
    using P = pair<double, int>;
    priority_queue<P, vector<P>, greater<P>> pq;
    h[T] = 0; pq.push({0, T});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > h[u]) continue;
        for (auto [v, w] : rg[u])
            if (h[u] + w < h[v]) { h[v] = h[u] + w; pq.push({h[v], v}); }
    }
}

struct Node {
    double f, g; int u;
    bool operator>(const Node& o) const { return f > o.f; }
};

double kthShortest(int n, int S, int T, int K) {
    dijkstraRev(n, T);
    if (h[S] >= INF / 2) return -1;
    if (S == T) K++; // 若要求至少走一条边
    priority_queue<Node, vector<Node>, greater<Node>> pq;
    pq.push({h[S], 0, S});

    while (!pq.empty()) {
        auto cur = pq.top(); pq.pop();
        if (++cnt[cur.u] > K) continue; // 每个点最多出队 K 次
        if (cur.u == T && cnt[T] == K) return cur.g;
        for (auto [v, w] : g[cur.u]) {
            if (h[v] < INF / 2 && cnt[v] < K)
                pq.push({cur.g + w + h[v], cur.g + w, v});
        }
    }
    return -1;
}
